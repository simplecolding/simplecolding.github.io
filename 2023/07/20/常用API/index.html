注意事项

  • String对象的内容不可改变，称为不可变字符串对象，但是可以重新指向其他的字符串
  • “xxx”给出的字符串对象，会存储到字符串常量池（Hashtable），且相同内容的只存储一份
  • 通过new生成的字符串对象，每new一次都会产生一个新的对象在堆中
  • java存在编译优化机制，str=”a”+”b”+”c”会直接转化成”abc”
